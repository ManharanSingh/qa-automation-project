# Windows 10 Installation

## Objective

Install Windows 10 in a virtual machine to create
a controlled environment for IT Support practice.

## Steps

1. Created a new VM in VMware.
2. Assigned 4 GB RAM.
3. Assigned 2 CPU cores.
4. Created a virtual hard disk.
5. Attached the Windows 10 ISO.
6. Started the VM.
7. Completed Windows installation.
8. Logged into the Windows desktop.
9. Verified system information.

## Result

Windows 10 was successfully installed and the VM
is operational.
